# Güvenlik Politikası

Prism Aurora bir VS Code renk temasıdır; çalıştırılabilir kod veya arka uç hizmeti içermez.

Bir güvenlik sorunu olduğunu düşünüyorsan, sorunu yeniden oluşturmak için gereken adımlarla birlikte proje sahibine özel olarak bildir. Sorun çözülmeden hassas ayrıntıları herkese açık paylaşmaktan kaçın.
